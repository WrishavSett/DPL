Setup Docker service to convert media (mp4) to RTSP -
docker run --rm -it -v ./mediamtx.yml:/mediamtx.yml -p 18554:18554 bluenviron/mediamtx:latest-ffmpeg

Setup Ffmpeg to post media (mp4) to RTSP hosted by Docker -
ffmpeg -re -stream_loop -1 -i ./test-video.mkv -c:v libx264 -preset ultrafast -bf 0 -crf 23 -an -f rtsp -rtsp_transport tcp rtsp://localhost:18554/mystream -loglevel verbose
